# Президент — предвыборная гонка

Иллюстрированная пошаговая настольная игра для 2–6 участников. Исторические личности участвуют в современной избирательной кампании, приобретают влияние в городах, открывают штабы и соперничают за поддержку.

[Играть в браузере](https://mitrich2497.github.io/president-game/) · [Играть с друзьями через интернет](https://president-campaign-oct22.vlast2497.chatgpt.site/?multiplayer=1) · [Открыть в ВК](https://vk.ru/app54891960)

## Как играть

Выберите персонажа одной из четырёх фракций, задайте число участников и начните кампанию. За одним экраном могут играть люди и компьютерные соперники. Чтобы играть с друзьями из разных сетей, нажмите «Играть с друзьями», создайте комнату и отправьте приглашение. После выбора персонажей все подтверждают готовность, затем создатель запускает партию.

В игре 16 персонажей с особыми способностями, восемь округов и 24 города. Победа достигается при 51% поддержки для двух игроков, 41% для трёх или четырёх, 31% для пяти или шести либо при накоплении 15 млрд ₽. Правила и справочник городов доступны из меню.

## Версия на GitHub Pages

Одиночная игра и партия за одним экраном работают непосредственно на GitHub Pages. Музыка, иллюстрации и шрифты входят в сборку. Сохранение остаётся в браузере на том адресе, где проходила партия.

Кнопка «Играть с друзьями» открывает действующий сервер сетевых комнат. Там сохраняются прогресс и места участников. После перезагрузки вернитесь по приглашению в том же браузере. Комната хранится семь дней после последнего игрового действия. Начатая партия принимает возвращающихся участников по их сохранённым ключам.

## Запуск на компьютере

Установите Node.js 24 или новее. Скачайте репозиторий, откройте его папку в терминале и выполните

```sh
npm start
```

Откройте `http://localhost:4175/`. Для запуска игры и локального сервера установка зависимостей не требуется. Сервер показывает адрес для подключения телефона из той же сети.

Порт задаётся переменной `PORT`, адрес прослушивания — `HOST`. Сетевые сохранения хранятся в `work/rooms`, другой путь задаётся через `ROOM_DIRECTORY`. Для доступа из интернета серверу нужен HTTPS и постоянное хранилище этой папки.

## Проверка и сборка

```sh
npm test
npm run build
```

Статическая версия появится в `dist/pages`. В ней уже настроен переход к публичному серверу комнат. Для другого сервера измените адрес `online` в `build-pages.mjs`.

GitHub Actions проверяет игру, собирает статические файлы и публикует их при обновлении ветки `main`. В настройках репозитория выберите **Pages → Source → GitHub Actions**.

Для серверной сборки Cloudflare Worker установите зависимости командой `npm install`, затем выполните `npm run build:hosted`. Исходник Worker находится в `worker/index.js`, миграции D1 — в `drizzle/`. Серверной среде требуются привязки `DB` и `ASSETS`.

## Содержимое проекта

- `web/` — интерфейс, игровые правила, изображения, музыка и звуки.
- `server.mjs`, `multiplayer.mjs`, `multiplayer-core.mjs` — сервер комнат для Node.js.
- `worker/` и `drizzle/` — сервер комнат и схема базы для Cloudflare.
- `tests/` — проверки правил, сетевых комнат и восстановления прогресса.
- `build-pages.mjs` — сборка для GitHub Pages.

## Текущий состав

В цифровой версии реализованы 10 событий «Чёрный лебедь», 5 командировок и 6 карт «Юрист». До полного состава настольной версии остаются остальные карты, залоги и банкротство.

Лицензии и сведения об исходниках шрифтов, звуков и VK Bridge находятся рядом с соответствующими файлами в `web/assets` и `web/vendor`. Авторские изображения и игровые правила публикуются в составе проекта. Общая лицензия на их повторное использование пока не назначена.
